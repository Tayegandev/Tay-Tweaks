# Tay Tweaks

**Windows Optimization & Gaming Utility**

Tay Tweaks is a Windows optimization application designed to help users manage system settings, improve gaming performance, and customize their Windows experience.

## Features

- Gaming and performance tweaks
- Windows optimization
- Registry optimization
- Restore point support
- Per-tweak application reporting
- Rollback and logging
- CPU, RAM and GPU monitoring

## Version

Current development version: **4.4**

## Updates

Tay Tweaks is planned to use GitHub Releases for version distribution and in-app updates.
